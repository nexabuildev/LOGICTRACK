# Recursos Estáticos (`src/assets/`)

Este directorio está reservado para almacenar todos los recursos multimedia estáticos locales utilizados en la interfaz de usuario.

## Recursos Actuales

*   **`hero.png`**: Imagen de cabecera/portada o fondo para la página principal o paneles de bienvenida.
*   **`react.svg`**: Logotipo vectorial oficial de React.
*   **`vite.svg`**: Logotipo vectorial de la herramienta de empaquetado Vite.

## Qué debe incluirse aquí
*   Imágenes de marca, isotipos y logotipos.
*   Iconografía personalizada en formato vectorial (SVG) o rasterizado (PNG/JPG).
*   Fuentes locales (si no se cargan externamente).
*   Archivos de audio/video necesarios para la UI.
