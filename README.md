# SaaS LogiTrack - ERP de Gestión Logística y Alquiler de Hardware

Plataforma empresarial full-stack para el control de inventariado, alquiler y venta de hardware de alto rendimiento, optimizada con Inteligencia Artificial.

## Stack Tecnológico
- **Frontend:** React (Vite)
- **Backend:** Spring Boot 3 (Java 17+)
- **Base de Datos:** PostgreSQL
- **Infraestructura:** Docker & GitHub Actions (CI/CD)
